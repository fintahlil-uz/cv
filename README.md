# CV Studio

CV, ma’lumotnoma, tarjimai hol va arizani telefonda bepul tayyorlash uchun veb-ilova.

- 107 ta maket, jumladan milliy naqshli maketlar
- O‘zbek, ingliz va rus tilidagi CV
- Ma’lumotlar faqat foydalanuvchi qurilmasida saqlanadi, serverga yuborilmaydi
- Telefonga ilova sifatida o‘rnatiladi va internetsiz ishlaydi

Ilovani ochish: https://fintahlil-uz.github.io/cv/

Muallif: [FinTahlil.uz](https://instagram.com/fintahlil.uz)

## Yangilash

1. `index.html` faylini yangisiga almashtiring.
2. `sw.js` ichidagi `CACHE` nomini yangi versiyaga o‘zgartiring (masalan, `cvstudio-v1.1`).
3. `index.html` ichidagi `APPV` qiymatini ham shu versiyaga o‘zgartiring.

Sayt manzilini (repozitoriy nomini) o‘zgartirmang: foydalanuvchilarning ma’lumotlari aynan shu manzilga bog‘langan.
